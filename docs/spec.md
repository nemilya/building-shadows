# ShadeMap: лицензия, выгрузка и открытые аналоги

Коротко: сам ShadeMap закрытый, и выгрузки данных у него нет. Но почти все данные, из которых он строит тени, открытые, и их можно скачать напрямую.

## Что можно и чего нельзя

| Что | Статус |
|---|---|
| Сайт shademap.app | Бесплатно только для просмотра. Платный Pro даёт более свежие данные и 3D-рельеф |
| Библиотеки `leaflet-shadow-simulator`, `mapbox-gl-shadow-simulator` | **Не open source.** В npm указано `License: UNLICENSED`, то есть проприетарная лицензия. Нужен API-ключ, его выдают на [shademap.app/about](https://shademap.app/about/). Есть тариф для личных проектов, коммерческое использование платное |
| Выгрузка теней или высот (GeoJSON, GeoTIFF) | Официально её нет. Скачивать их тайлы скриптом — нарушение условий использования, и в этом нет смысла (см. ниже) |
| Точные данные (LiDAR, фотограмметрия, около 30 см) | Платно, оплата за км² на месяц. Покрытие есть не везде, по Екатеринбургу нужно проверять |

Их библиотеку можно подключить к своей карте Leaflet или Mapbox/MapLibre со своим ключом и подавать ей свои здания через `getFeatures` (GeoJSON с высотами) и свой рельеф через `terrainSource`. Так вы получите их движок теней, но под их лицензией.

## Откуда ShadeMap берёт данные (всё это можно скачать самому)

| Слой | Источник | Лицензия |
|---|---|---|
| **Здания** | [Overture Maps](https://overturemaps.org) — объединяет OSM с данными Microsoft, Google и других. Обновляется ежемесячно | Здания из OSM — **ODbL**, остальные — в основном CDLA-Permissive 2.0 / CC BY. Источник указан у каждого здания в поле `sources` |
| **Рельеф** | AWS Terrain Tiles (формат terrarium) — их же URL стоит в примере из документации | Бесплатно, с указанием источников (SRTM и др.) |
| **Деревья** | Meta/WRI Global Canopy Height, разрешение около 1 м, оценка ML по спутниковым снимкам | **CC BY 4.0** |

Значит, данные для Екатеринбурга можно получить такие же, как у ShadeMap, а то и свежее.

### Здания Overture для Екатеринбурга

```bash
pip install overturemaps
overturemaps download --bbox=60.45,56.70,60.80,56.95 \
  -f geojson --type=building -o ekb_buildings.geojson
```

Полезные поля: `height`, `num_floors`, `min_height`, `roof_shape`, `sources`. Если `height` пустой, считайте `num_floors × 3` м, а если нет и этажности, берите значение по умолчанию.

### Деревья (Meta Canopy Height)

Данные лежат в открытом бакете AWS `s3://dataforgood-fb-data/forests/v1/` в виде GeoTIFF-тайлов, скачать можно без аккаунта (`aws s3 ls --no-sign-request ...`).

## Что требует лицензия ODbL (для данных OSM)

- **Указание авторства обязательно:** «© OpenStreetMap contributors» (плюс Overture, Meta и другие источники, если вы их используете).
- **Готовые картинки, тайлы и карты теней** по ODbL считаются «произведённой работой» (Produced Work). Для них достаточно указать авторство, свою картинку можно распространять под любой лицензией.
- **Если вы распространяете саму базу** (например, GeoJSON с дополненными высотами), она тоже должна быть под ODbL (share-alike).

## Открытые инструменты, чтобы считать тени самому

- **deck.gl** (MIT): 3D-выдавливание зданий плюс `LightingEffect` с `_SunLight` и тенями. Это самый быстрый путь к веб-карте теней по времени.
- **Three.js** (MIT): если нужен полный контроль над рендерингом.
- **pybdshadow** (Python): векторные тени зданий по времени, умеет считать суммарную освещённость за день.
- **GRASS GIS** `r.sun` / `r.sunmask` и **QGIS** (GPL): растровый расчёт по цифровой модели поверхности (рельеф + здания + деревья).
- **suncalc** (JS) и **pvlib** (Python): положение солнца.
